# 「发明」孙子兵法 · 十三篇

*Inventing the Art of War — the thirteen chapters.*

十三关，一篇一决策。每关一个战场局面、一个决定、一次结算。结算之后，你先用自己的话写下这一仗的教训，游戏才把原文给你看。十三关打完，竹简上那十三条，是你自己一仗一仗写出来的《孙子兵法》。

然后是第十四关。

- 四档语气：文言 / 白话 / 黑话 / ENG（默认白话；黑话需手动解锁）
